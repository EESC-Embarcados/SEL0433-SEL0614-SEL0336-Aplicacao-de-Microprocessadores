# SEL0433 / SEL0614 / SEL0336 — Aplicação de Microprocessadores

Este repositório reúne materiais de apoio, exemplos práticos, atividades semanais e projetos semestrais relacionados às disciplinas de **Aplicação de Microprocessadores**, oferecidas nos cursos da EESC-USP sob os códigos **SEL0433**, **SEL0614** e **SEL0336**.

---

## Organização do Repositório

* **Atividades\_Semanais/**
  Conjunto de exercícios e desafios práticos semanais, abordando tópicos essenciais de programação de microcontroladores, análise de sinais, timers, periféricos e outros.

* **ESP\_32/** *(submódulo)*
  Repositório externo contendo exemplos e tutoriais focados no desenvolvimento com ESP32, utilizados nas aulas e projetos.

* **PIC/** *(submódulo)*
  Repositório externo com exemplos, tutoriais e materiais relacionados ao microcontrolador PIC18F4550, incluindo o uso da placa virtual **PICGenios** em simuladores como **PICSimLab**.

* **Projetos/**
  Diretório com descrições e códigos dos projetos finais desenvolvidos pelos alunos ao longo do semestre.
